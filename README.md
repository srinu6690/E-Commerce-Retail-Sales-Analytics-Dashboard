# 🛒 E-Commerce & Retail Sales Analytics Dashboard (Dark Mode)

A professional, portfolio-grade Power BI dashboard designed to analyze retail sales performance, regional revenue contributions, and profit margins with a modern dark UI/UX theme.

---

## 🚀 Key Features & Visuals
- **Dark Mode UI/UX:** Built with a cohesive dark theme (`#0B132B`, `#0D1B2A`), 8px rounded borders, and a custom color palette for clean visual hierarchy.
- **KPI Summary Cards:** Real-time tracking of Total Profit, Total Orders, Profit Margin %, and Total Revenue.
- **Visualizations:**
  - **Donut Chart:** Revenue Contribution by Region.
  - **Clustered Bar Chart:** Profit Analysis by State & Segment.
  - **Bar Chart:** Revenue breakdown by Product Category & Sub-Category.
- **Interactive Slicers:** Custom Button Slicers for *Region* and *Sub-Category*, paired with a dynamic *Date Range* slider.
- **Reset Functionality:** Integrated Bookmark-powered **Reset Filters** button for seamless user experience.

---

## 🛠️ Tools & Technologies Used
- **Microsoft Power BI Desktop** (Data Modeling, DAX, Power Query)
- **Data Visualization & UX Design Principles** (Dark Theme Styling, Alignment, Custom Button States)
- **Git & GitHub** (Version Control & Portfolio Showcasing)
